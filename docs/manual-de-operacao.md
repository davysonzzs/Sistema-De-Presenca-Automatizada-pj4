
# 📘 Manual de Operação — Sistema de Presença Automatizada

## 1. Como trabalhamos

### Como as tarefas chegam até a equipe?

As tarefas chegam por meio das atividades propostas pelo professor e das necessidades identificadas durante o desenvolvimento do Sistema de Presença Automatizada.

A equipe analisa o que precisa ser feito e organiza as atividades de acordo com os objetivos do projeto.

### Como decidimos quem faz o quê?

As tarefas são divididas de acordo com as responsabilidades de cada integrante.

- Aristisdes: organiza as prioridades e acompanha o produto.
- José Henrique: cuida da comunicação com os usuários.
- Taislan: analisa a experiência dos usuários.
- Davyson: cuida da tecnologia e organização.
- João Victor: planeja o marketing e a divulgação.

Quando uma atividade envolve mais de uma responsabilidade, os integrantes podem trabalhar juntos.

### Como sabemos que uma tarefa está pronta?

Uma tarefa está pronta quando:

- [ ] A atividade solicitada foi realizada.
- [ ] O resultado foi revisado.
- [ ] Os possíveis erros foram identificados.
- [ ] A documentação foi atualizada, quando necessário.
- [ ] Outro integrante conferiu o resultado.
- [ ] Os arquivos foram enviados ao GitHub, quando aplicável.

### O que fazemos quando alguém trava?

Quando alguém encontra uma dificuldade, comunica o problema aos outros integrantes, explicando o que está tentando fazer e o que já tentou.

A equipe procura ajudar a encontrar uma solução. Se ninguém conseguir resolver, podemos pesquisar ou pedir orientação ao professor.

## 2. Combinados de comunicação

| Combinado | O acordo da nossa equipe |
|---|---|
| Tempo de resposta esperado | Procuramos responder às mensagens assim que possível, preferencialmente no mesmo dia. |
| Horário em que ninguém precisa responder | Fora do horário das atividades escolares, ninguém precisa responder imediatamente. |
| Qual canal para cada assunto | WhatsApp para conversas e alinhamentos; GitHub para arquivos e documentação. |
| O que conta como urgente | Problemas que impedem a realização das atividades ou comprometem uma entrega. |

## 3. Modelo de pedido de ajuda

1. O que eu quero fazer?
2. O que está acontecendo?
3. Onde está o problema? (arquivo, tela ou funcionalidade)
4. O que eu já tentei?
5. O que eu preciso de você?

## 4. Modelo de daily por texto

**ONTEM:** O que consegui fazer?

**HOJE:** O que pretendo fazer?

**TRAVADO:** Qual dificuldade estou enfrentando?

## 5. Atualização do manual

Este documento poderá ser atualizado quando a equipe modificar sua maneira de trabalhar ou estabelecer novos combinados.
